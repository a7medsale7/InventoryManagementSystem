# الوحدة 0: افهم المطلوب قبل ما تكتب سطر كود

## المطلوب بالبساطة

المطلوب منك **برنامج Desktop** (نافذة بتفتحها على الكمبيوتر) لإدارة مخزن صغير. البرنامج بيعمل 4 حاجات أساسية:

| # | المتطلب في التاسك | يعني إيه بالبلدي | هنحله بإيه |
|---|---|---|---|
| 1 | Manage Inventory | تضيف / تعدّل / تمسح منتجات | Windows Forms + ADO.NET + جدول Products |
| 2 | Generate Reports | تقرير مطبوع فيه ملخص المخزون والمنتجات اللي قربت تخلص مظللة | Crystal Reports |
| 3 | Authentication & Roles | شاشة Login، وفيه Admin يعمل كل حاجة وViewer يشوف بس، والباسورد متخزنش كنص عادي | جدول Users + PBKDF2 Hashing |
| 4 | Search & Filter | بحث بالاسم، وفلتر بالفئة، وفلتر بحالة المخزون | Query بـ Parameters |
| ⭐ | Audit Logging (اختياري) | تسجيل أي تعديل: مين عمله وإمتى والقيم القديمة والجديدة | جدول AuditLogs + Transaction |
| ⭐ | Telerik Grid (اختياري) | جدول أشيك فيه بحث وفلترة جاهزة | RadGridView (ملحق في آخر الملف) |

> **كلمة "Terlik" في التاسك** هي **Telerik**. شركة بتبيع مكتبة controls جاهزة لـ WinForms. دي اختيارية تمامًا، ومتغطية في الوحدة 13.

## القرارات اللي أنا خدتها عنك (عشان متتلخبطش)

- **اللغة:** C# .
- **نوع المشروع:** Windows Forms App **(.NET Framework 4.8)**. مش .NET 6/7/8. السبب: Crystal Reports for Visual Studio بتشتغل مع .NET Framework بس.
- **قاعدة البيانات:** SQL Server Express (مجاني) + SSMS.
- **الوصول للداتا:** ADO.NET صافي (`SqlConnection`, `SqlCommand`, `SqlDataAdapter`, `SqlDataReader`) بدون Entity Framework.
- **إضافة صغيرة مني:** جدول `Categories` وعمود `CategoryId` في المنتجات. التاسك بيطلب "Filter by category" لكن مش حاطط Category في تفاصيل المنتج، فمحتاجينها.

## شكل البرنامج من جوه (Architecture)

بنقسم الكود لطبقات. ده بيخلي الكود منظم، وبيخليك تشرح للدكتور أو المهندس بسهولة:

```
+---------------------------------------------------+
|  Forms (الشاشات)  LoginForm / MainForm / ...       |  <- اللي المستخدم بيشوفه
+---------------------------------------------------+
|  Repositories (Data)  ProductRepository ...        |  <- كل كود SQL هنا بس
+---------------------------------------------------+
|  Security: PasswordHasher  |  Session (مين مسجل دخول)|
+---------------------------------------------------+
|  SQL Server:  Users / Products / Categories /     |
|               AuditLogs                            |
+---------------------------------------------------+
```

**القاعدة الذهبية:** الشاشة (Form) عمرها ما تكتب SQL. هي بس بتنادي على الـ Repository.

# الوحدة 2: إنشاء قاعدة البيانات

**الهدف:** تبني 4 جداول: `Users`, `Categories`, `Products`, `AuditLogs`.

## فكرة كل جدول

- **Users**: المستخدمين. بنخزن فيه **PasswordHash** مش الباسورد نفسه.
- **Categories**: فئات المنتجات (إلكترونيات، أدوات مكتبية...).
- **Products**: المنتجات. فيها كل التفاصيل المطلوبة + `CategoryId`.
- **AuditLogs**: سجل التعديلات. عمدًا **مفيهوش Foreign Key** على Products، لأنك لو مسحت منتج، السجل بتاعه لازم يفضل موجود.

## الخطوات

1. افتح SSMS ← اتصل ← اضغط **New Query**.
2. الصق السكريبت ده كامل واضغط **Execute (F5)**.

```sql
-- 1) إنشاء الداتا بيز
IF DB_ID('InventoryDB') IS NULL
    CREATE DATABASE InventoryDB;
GO
USE InventoryDB;
GO

-- 2) جدول المستخدمين
CREATE TABLE Users (
    UserId       INT IDENTITY(1,1) PRIMARY KEY,
    Username     NVARCHAR(50)  NOT NULL UNIQUE,
    PasswordHash NVARCHAR(255) NOT NULL,       -- Hash مش باسورد عادي
    Role         NVARCHAR(20)  NOT NULL
                 CONSTRAINT CK_Users_Role CHECK (Role IN ('Admin','Viewer')),
    IsActive     BIT           NOT NULL DEFAULT 1,
    CreatedAt    DATETIME2     NOT NULL DEFAULT SYSDATETIME()
);

-- 3) جدول الفئات
CREATE TABLE Categories (
    CategoryId INT IDENTITY(1,1) PRIMARY KEY,
    Name       NVARCHAR(100) NOT NULL UNIQUE
);

-- 4) جدول المنتجات
CREATE TABLE Products (
    ProductId    INT IDENTITY(1,1) PRIMARY KEY,
    Name         NVARCHAR(100) NOT NULL,
    Description  NVARCHAR(500) NULL,
    Quantity     INT           NOT NULL CONSTRAINT CK_Products_Qty   CHECK (Quantity >= 0),
    Price        DECIMAL(18,2) NOT NULL CONSTRAINT CK_Products_Price CHECK (Price >= 0),
    SupplierName NVARCHAR(100) NOT NULL,
    CategoryId   INT           NULL
                 CONSTRAINT FK_Products_Categories REFERENCES Categories(CategoryId)
);
CREATE INDEX IX_Products_Name ON Products(Name);

-- 5) جدول سجل التعديلات
CREATE TABLE AuditLogs (
    AuditId     INT IDENTITY(1,1) PRIMARY KEY,
    ActionType  NVARCHAR(10)   NOT NULL,        -- INSERT / UPDATE / DELETE
    ProductId   INT            NULL,
    ProductName NVARCHAR(100)  NULL,
    UserId      INT            NOT NULL,
    Username    NVARCHAR(50)   NOT NULL,
    ChangedAt   DATETIME2      NOT NULL DEFAULT SYSDATETIME(),
    OldValues   NVARCHAR(MAX)  NULL,
    NewValues   NVARCHAR(MAX)  NULL
);
GO

-- 6) بيانات أولية
INSERT INTO Categories (Name) VALUES
 (N'Electronics'), (N'Office Supplies'), (N'Furniture'), (N'Food & Drinks'), (N'Other');

INSERT INTO Products (Name, Description, Quantity, Price, SupplierName, CategoryId) VALUES
 (N'Wireless Mouse', N'2.4GHz optical mouse',   40, 250.00, N'TechSource', 1),
 (N'Keyboard',       N'USB keyboard',            6, 400.00, N'TechSource', 1),
 (N'A4 Paper Pack',  N'500 sheets',              3,  95.00, N'PaperWorld', 2),
 (N'Office Chair',   N'Ergonomic chair',        12, 1800.00, N'FurniCo',   3),
 (N'Printer Ink',    N'Black cartridge',         0, 650.00, N'PaperWorld', 2);
GO
```

## ملاحظات مهمة

- **مفيش مستخدمين في السكريبت.** السبب إن الباسورد لازم يتعمله Hash بالكود بتاعنا، فهنعمل المستخدمين أول ما البرنامج يشتغل (الوحدة 7).
- `CHECK (Quantity >= 0)`: حتى لو الكود غلط، الداتا بيز نفسها ترفض كمية سالبة. دي طبقة حماية تانية.
- الـ `N'...'` قبل النص معناها Unicode، عشان يدعم أي لغة.

شغّل `SELECT * FROM Products;` لازم تشوف 5 صفوف. وشغّل `SELECT name FROM sys.tables;` لازم تشوف الجداول الأربعة.

# الوحدة 3: إنشاء المشروع والهيكل

**الهدف:** مشروع فاضي بهيكل فولدرات منظم.

## الخطوات

1. Visual Studio ← **Create a new project** ← اختار **Windows Forms App (.NET Framework)** (مش النسخة اللي مكتوب جنبها .NET بس). **اللغة C#**.
2. **Project name:** `InventorySystem` ← **Framework: .NET Framework 4.8** ← Create.
3. من Solution Explorer: **امسح** `Form1.cs` (كليك يمين ← Delete). هنعمل شاشاتنا بنفسنا.
4. اعمل الفولدرات دي: كليك يمين على المشروع ← Add ← New Folder:
   - `Models`
   - `Data`
   - `Security`
   - `Forms`
   - `Reports`
5. **أضف مرجع (Reference) لـ System.Configuration:** كليك يمين على **References** ← Add Reference ← Assemblies ← Framework ← علّم على `System.Configuration` ← OK.
6. **اضبط الـ Platform:** من Build ← Configuration Manager، خلّي Active solution platform = **x64** (لو مفيش، اختار New ← x64). وكمان من Properties المشروع ← Build ← شيل علامة **Prefer 32-bit** لو موجودة. ده مهم عشان Crystal Reports، مفروض يتطابق مع الـ runtime اللي نزّلته (64-bit).
7. افتح `App.config` وخليه كده بالظبط (غيّر اسم السيرفر لو مختلف):

```xml
<?xml version="1.0" encoding="utf-8" ?>
<configuration>
  <connectionStrings>
    <add name="InventoryDb"
         connectionString="Data Source=.\SQLEXPRESS;Initial Catalog=InventoryDB;Integrated Security=True"
         providerName="System.Data.SqlClient" />
  </connectionStrings>

  <appSettings>
    <!-- أي منتج كميته أقل من الرقم ده يعتبر Low Stock -->
    <add key="LowStockThreshold" value="10" />
  </appSettings>

  <startup>
    <supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8" />
  </startup>
</configuration>
```

> لو الـ `<startup>` اللي عندك فيه أرقام مختلفة، سيبه زي ما هو. المهم تضيف `connectionStrings` و `appSettings`.

## الـ Session: مين اللي مسجل دخول دلوقتي؟

**Security/Session.cs** (كليك يمين على فولدر Security)

```csharp
using System;
using InventorySystem.Models;

namespace InventorySystem.Security
{
    public static class Session
    {
        public static User CurrentUser { get; set; }

        public static bool IsAdmin
        {
            get { return CurrentUser != null && CurrentUser.Role == Role.Admin; }
        }

        // بنناديها قبل أي عملية تعديل. حماية حتى لو الزرار اتخفى غلط.
        public static void RequireAdmin()
        {
            if (!IsAdmin)
                throw new UnauthorizedAccessException("This action requires Admin role.");
        }
    }
}
```

# الوحدة 5: الاتصال بالداتا بيز

**الهدف:** مكان واحد بنفتح منه Connection.

**Data/Db.cs**

```csharp
using System.Configuration;
using System.Data.SqlClient;

namespace InventorySystem.Data
{
    public static class Db
    {
        private static readonly string _connectionString =
            ConfigurationManager.ConnectionStrings["InventoryDb"].ConnectionString;

        public static SqlConnection GetConnection()
        {
            return new SqlConnection(_connectionString);
        }

        // يحوّل null لـ DBNull عشان SQL تفهمه
        public static object ToDb(object value)
        {
            return value ?? System.DBNull.Value;
        }
    }
}
```

**Data/AppSettings.cs**

```csharp
using System.Configuration;

namespace InventorySystem.Data
{
    public static class AppSettings
    {
        public static int LowStockThreshold
        {
            get
            {
                int value;
                return int.TryParse(ConfigurationManager.AppSettings["LowStockThreshold"], out value)
                    ? value : 10;
            }
        }
    }
}
```

## شرح سريع لأدوات ADO.NET اللي هنستخدمها

| الكلاس | بيعمل إيه |
|---|---|
| `SqlConnection` | الاتصال بالداتا بيز |
| `SqlCommand` | بيشيل جملة SQL + الـ Parameters |
| `SqlDataReader` | بيقرأ النتيجة صف بصف (سريع) |
| `SqlDataAdapter` + `DataTable` | بيجيب نتيجة كاملة في جدول في الذاكرة. مناسب للـ Grid |
| `SqlTransaction` | يخلي أكتر من عملية تنجح كلها أو تفشل كلها |
| `using (...) { }` | بيقفل الـ Connection أوتوماتيك حتى لو حصل Error |

> **قاعدة أمان:** عمرك ما تركّب SQL بالـ `+` مع اللي المستخدم كتبه (`"... WHERE Name='" + txt.Text + "'"`). ده بيفتح باب **SQL Injection**. استخدم دايمًا **Parameters** (`@name`).
